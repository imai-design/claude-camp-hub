全員でやる8ステップ

  1. デスクトップに claude-camp フォルダを作成
    デスクトップで 右クリック → 新規フォルダ（Windows は「新規作成 → フォルダー」）。名前を claude-camp にする。Mac / Windows 共通の作り方です。
  2. 配布物(zip)をダウンロードして、解凍したフォルダを claude-camp の中に入れる
  3. VS Codeをダウンロード & インストール
    https://code.visualstudio.com/download サイトを開く ↗
    配布物内の VSCode手順書.txt も合わせてご覧ください。
  4. Claude アカウントを作成
    https://claude.ai/new サイトを開く ↗
  5. Pro 契約（クレジットorデビットカードが必要、案内致します）
  6. Claude デスクトップアプリをダウンロード & インストール
  7. デスクトップアプリにサインイン
  8. モデル指定:/model opusplan をデフォルトに設定
なぜ opusplan か: Plan モードは Opus(複雑な思考)、実装は Sonnet(速度)を自動で切り替えるモードです。コストを抑えつつ、パワーは落とさず使えます。今日の標準設定です。

VS Code 拡張で Claude Code を動かす — IDE で完結する

ターミナルから claude を起動するだけでなく、VS Code の中に Claude Code パネルを常駐させて使うこともできます。コードを編集しながら横で対話できるので、ファイル編集や差分確認、コードレビューが一気にラクになります。9:00 セットアップで VS Code を入れていただいたのは、ここで効いてきます。

What you can do
  • ✓  VS Code の右側（または好きな場所）に Claude のチャットパネルを常駐
  • ✓  エディタで選択した範囲を Claude が自動で認識
  • ✓  提案された変更を 差分(diff)表示 で確認 → ワンクリック承認 / 拒否
  • ✓  @ファイル名 で特定のファイル / フォルダを参照
  • ✓  セッション履歴の検索・復元、複数会話を別タブで並行
  • ✓  Plan モードでは 計画書がマークダウンで開くので、コメント付けてから承認できる
必要なもの
  • VS Code 1.98 以上（Help → About で確認できます）
  • Anthropic アカウント（Claude Pro / Max などのサブスク契約）
  • Node.js 18 以上（Claude Code を既に入れている方は OK）
手順① インストール
  1. VS Code を開く
  2. 拡張機能ビューを開く：Cmd+Shift+X（Mac） / Ctrl+Shift+X（Windows）
  3. 検索欄に 「Claude Code」 と入力
  4. 発行元が「Anthropic」のものを選んで「Install」をクリック
  5. インストール完了後、もし反映されなければコマンドパレットで Developer: Reload Window を実行
https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code マーケットプレイスを開く ↗
手順② サインイン
  1. VS Code 左サイドバーの Spark アイコン（✱） をクリック
  2. パネル上部の「Sign in」ボタンを押す
  3. ブラウザが開くので、Claude アカウントで認可（許可）する
  4. VS Code に戻ると、サインイン完了

サインイン画面が出続けるときは、ターミナルから code . で VS Code を起動すると環境変数を引き継いでくれて解決することがあります。

手順③ 開き方（4 通り）
  • エディタ右上の Spark アイコン（ファイルを開いているときに表示）
  • 左サイドバーの Spark アイコン（常時表示・セッション一覧が見える）
  • 右下ステータスバー「✱ Claude Code」（ファイル未オープンでも可）
  • コマンドパレット：Cmd+Shift+P → 「Claude Code」と入力
手順④ 基本の使い方
  1. ファイルを開いて、コードを範囲選択すると、Claude が自動で内容を見ます
  2. パネル下のプロンプト欄に質問・指示を入力 → Enter で送信
  3. Claude が変更を提案 → 差分が表示される → 「Accept / Reject」で判断
  4. ファイルを明示的に参照するときは @ファイル名（部分一致OK）。フォルダは末尾に /(例: @src/components/)
  5. 選択範囲を行番号付きで参照：Option+K（Mac） / Alt+K（Windows）で @app.ts#5-10 のような参照を自動挿入
便利なショートカット
Mac / Windows できること
Cmd+Esc / Ctrl+Escエディタ ⇄ Claude のフォーカス切替
Cmd+Shift+Esc / Ctrl+Shift+Esc新規会話を別タブで開く
Option+K / Alt+K選択範囲を @-mention でプロンプトに挿入
Shift+Enterプロンプトで改行（送信せず）
Cmd+, / Ctrl+,設定を開く → Extensions → Claude Code
ターミナル版（claude コマンド）との関係
  • VS Code 拡張とターミナル版は 会話履歴を共有 しています
  • 拡張で始めた会話をターミナルで続けるには claude --resume
  • VS Code 内のターミナルで claude を起動すると 自動的に IDE と連携（diff 表示などが効く）
よくあるトラブル
  • Spark アイコンが見えない → ファイルを1つ開いてから確認 / VS Code を再起動（Developer: Reload Window） / 他の AI 拡張（Cline、Continue など）を一時的に無効化
  • Mac で Cmd+Esc が効かない → システム設定 → キーボード → キーボードショートカット → ゲームコントローラー の「Game Overlay」のチェックを外す
  • ログイン画面が出続ける → ターミナルから code . で起動して環境変数を引き継ぐ
  • 反応がない → 新しい会話を始める / 一度 claude をターミナルで起動して詳細エラーを確認
