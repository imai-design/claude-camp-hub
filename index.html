全員でやる6ステップ

  1. 配布物(zip)をダウンロードして、解凍する（デスクトップなど分かりやすい場所に置いておく）
  2. Claude アカウントを作成
    https://claude.ai/new サイトを開く ↗
  3. Pro 契約（クレジットorデビットカードが必要、案内致します）
  4. Claude デスクトップアプリをダウンロード & インストール
  5. デスクトップアプリにサインイン
  6. モデル指定:/model opusplan をデフォルトに設定
なぜ opusplan か: Plan モードは Opus(複雑な思考)、実装は Sonnet(速度)を自動で切り替えるモードです。コストを抑えつつ、パワーは落とさず使えます。今日の標準設定です。

Git 登録

Claude Code が裏で使う必須ツールです。お使いの OS に合わせてセットアップしてください。

  1. Windows — 公式インストーラを使う
    https://git-scm.com/install/windows サイトを開く ↗
    ダウンロードした .exe を起動 → ほぼ「次へ」連打で OK。
  2. Mac — ターミナルにコマンドを貼り付ける
    xcode-select --install
    アプリ「ターミナル」を開いて貼り付け → Enter。ポップアップが出たら 「インストール」 を押す（数分かかります）。

警告メッセージへの心得

このコマで入れるもの

PLAYWRIGHT
ブラウザを Claude に運転させる道具。 普段マウスでやっている「サイトを開く / ボタンを押す / 文字を打つ / スクショを撮る」を、Claude Code が自動で行えるようになります。午後の「不足品の発注」で実際に画面を動かすために、午前のうちに入れておきます。
例: 発注サイトに自動ログイン → 数量を入力 → 注文確定 → 完了画面のスクショを保存
PDFTOTEXT
PDF を「読める文字データ」に変換する道具。 領収書や請求書の PDF は、そのままでは Claude が中身を扱いづらい状態（紙のスキャン画像と同じ扱い）です。pdftotext を通すと、PDF の中身をテキストとして取り出せるので、金額・日付・店名などを自動で抜き出せるようになります。
例: 経費 PDF を読み込ませて、金額と日付を経費精算フォームに自動入力
なぜ今このタイミング? どちらも「初回だけインストールが必要 / 一度入れたらずっと使える」道具です。午後の 14:00 発注+経費 セッションで両方を使うので、午前のうちにセットアップを済ませてしまいます。インストールで詰まったら遠慮なく挙手してください。

— Section 04 / Field Manual

作法と安全。

迷ったり、警告画面が出たり、Cowork が固まったり。今日のフィールドで覚えておきたいことを、まとめました。

Safety Notice
警告メッセージが出ても、大丈夫。
ブラウザは皆さんを守るために『念のため』の警告を出してきます。今日触るのは、すべてダミーサイトです。何が起きても、実害はありません。困ったら、すぐ手を挙げてください。一緒に対応します。

本物の業務で警告が出たら:

  • ①そのサイト、本当に自分が使っているサービスですか?
  • ②入力するのは、本当の個人情報・パスワードですか?

どちらかでも「はい」なら、警告を無視せず、ちゃんと読んで判断してください。

Cowork Manual
Cowork にできること、できないこと。
  • ✓フォーム入力
  • ✓ボタンクリック / ページ遷移
  • ✓画面に表示されている要素の認識
  • ✕ファイルアップロード
Cowork と Code の使い分け
Cowork
GUI 担当
画面に「見えるもの」を操作。マウスでクリックする世界。
  • ブラウザでサイトを開く
  • フォーム入力 / ボタンクリック
  • 画面に表示された情報を読み取る
  • ページ遷移を伴う作業全般
Code
CUI 担当
PC の「裏側」を操作。文字コマンドで動かす世界。
  • ファイル / フォルダの読み書き
  • コード生成 / HTML 作成 / ツール開発
  • ターミナルコマンドの実行
  • アプリ / 拡張機能のインストール
GUI = グラフィカル(画面の)ユーザーインターフェース／CUI = キャラクター(文字の)ユーザーインターフェース。Cowork で詰まったら Code に渡す — 両者を使い分けるのが、現実の業務スタイルです（14:00 セッションで実演します）。
