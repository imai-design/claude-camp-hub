全員でやる8ステップ

  1. 配布物(zip)をダウンロードして、解凍する
  2. デスクトップに claude-camp フォルダを作成
    mkdir -p ~/Desktop/claude-camp
    ターミナル(Mac は terminal.app)に貼り付けて Enter で、デスクトップに claude-camp フォルダができます。Finder から手作りでも OK です。
  3. Claude アカウントを作成
  4. Pro 契約(クレジットカードが必要・当日案内します)
  5. Claude デスクトップアプリをダウンロード & インストール
  6. デスクトップアプリにサインイン
  7. Claude Code を起動確認 → cd ~/Desktop/claude-camp → claude
  8. モデル指定:/model opusplan をデフォルトに設定
なぜ opusplan か: Plan モードは Opus(複雑な思考)、実装は Sonnet(速度)を自動で切り替えるモードです。コストを抑えつつ、パワーは落とさず使えます。今日の標準設定です。

# Claude Code で業務効率化!便利ツール2選 (動画の文字起こし) --- 皆さんこんにちは。今日はですね、Claude Code で業務効率化したい人向けに、私が実際に使ってみて「これは入れておくと絶対に便利だよ」というツールを2つ紹介していきたいと思います。 最近、Claude Code を使い始める人がすごく増えてきてるんですけど、「インストールしただけで止まってる」っていう人も多いと思うんですよね。せっかく使うなら、もう一歩踏み込んで、Claude Code から色々なツールを呼び出せるようにしておくと、できることが一気に広がります。 今日紹介する2つは、私が業務で実際に使っていて、「これがあるかないかで全然違う」ってものです。Mac でも Windows でも使えます。それでは早速見ていきましょう。 --- ## 1つ目:Playwright まず1つ目は Playwright です。 これ、何ができるかと言うと、ブラウザを自動操作できるツールなんです。例えば、毎日同じウェブサイトにログインして同じ作業をしている、みたいな人いると思うんですよね。経費精算システムに領収書情報を入力するとか、社内システムにデータを転記するとか。 そういうルーチンワークを、Playwright を使うと Claude Code が自動で代わりにやってくれるんです。ボタンをクリックする、フォームに文字を入力する、ページを移動する、こういうブラウザ上の操作を全部自動化できる。 実際、私の場合だと、毎月の経費申請が地獄だったんですけど、Playwright と Claude Code を組み合わせて、領収書の情報から自動で経費精算サイトに入力するようにしたら、もう本当に楽になりました。 Playwright のいいところは、Chrome、Firefox、Safari、全部のブラウザに対応してることですね。それと、画面を見ながらデバッグできる機能もあって、最初は「ちゃんと動いてるかな?」って心配な時も、画面を見ながら確認できる。 インストールはコマンド一発で済みます。Claude Code に「Playwright をインストールして」って頼めば、ブラウザ本体まで含めて全部セットアップしてくれます。これは入れておいて損はないですね。 --- ## 2つ目:pdftotext 2つ目は pdftotext です。 これは名前の通りで、PDF からテキストを抽出するツールです。「え、それだけ?」と思うかもしれないんですが、実はこれがめちゃくちゃ重要なんですよ。 なんでかと言うと、Claude Code 単体だと、実は PDF の中身を直接読むのが結構苦手なんです。PDFってファイルサイズが大きいことも多いし、画像として埋め込まれてるテキストもあったりして、Claude にそのまま渡すと処理が重い。 そこで pdftotext です。これを使うと、PDF からプレーンテキストだけをサクッと抜き出せる。抜き出したテキストを Claude に渡せば、すごく軽く処理できる。 例えば、領収書の PDF があったとします。これを pdftotext で処理すると、「2026年5月10日、Quick Office株式会社、合計2134円、明細:ボールペン、コピー用紙、コーヒー」みたいなテキストがパッと出てくる。あとはそれを Claude が読み取って、必要な処理をすればいい。 請求書の整理、契約書の確認、議事録の要約、PDFを扱う作業って意外と多いんですよね。pdftotext があると、それらが全部一気に楽になります。 これも Claude Code に「pdftotext をインストールして」と頼めば、必要なものを全部入れてくれます。Mac なら Homebrew 経由で、Windows なら WSL や別の方法で入りますが、Claude Code が状況を見て適切に対応してくれるはずです。 --- ## まとめ ということで、今日は Playwright と pdftotext、この2つを紹介しました。 両方とも、入れておけば Claude Code でできることが一気に広がります。逆に言うと、これらが入ってないと、Claude Code は「文章を生成する以上のこと」がしづらいんですよね。 なので、Claude Code を使い始めた人は、まず最初にこの2つだけは入れておくのをおすすめします。 それでは、また次の動画でお会いしましょう。チャンネル登録もよろしくお願いします。 --- (動画終了)

プランモードとは(参加者への説明)

プランモードは、Claude Code の機能の一つです。通常モードは Code がいきなり実装し始めます。プランモードは、まず「こういう順番で作ります」という計画を見せてくれます。計画を承認したら実装に進む、という流れです。

いきなり書かれて方向性違いの大手戻りを防げます。初めて Code を使う時は、プランモード推奨です。

— Section 04 / Field Manual

作法と安全。

迷ったり、警告画面が出たり、Cowork が固まったり。今日のフィールドで覚えておきたいことを、まとめました。

Safety Notice
警告メッセージが出ても、大丈夫。
ブラウザは皆さんを守るために『念のため』の警告を出してきます。今日触るのは、すべてダミーサイトです。何が起きても、実害はありません。困ったら、すぐ手を挙げてください。一緒に対応します。

本物の業務で警告が出たら:

  • ①そのサイト、本当に自分が使っているサービスですか?
  • ②入力するのは、本当の個人情報・パスワードですか?

どちらかでも「はい」なら、警告を無視せず、ちゃんと読んで判断してください。

Cowork Manual
Cowork にできること、できないこと。
  • ✓フォーム入力
  • ✓ボタンクリック / ページ遷移

  • ✕ファイルアップロード
  • ✕ダウンロードしたPDFや画像の中身チェック(限定的)
  • ✕主観的な判断
